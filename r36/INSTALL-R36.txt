BRICKCHORD, BRICKLAB and BRICKGLIDE for the R36S, R36Max and other ArkOS-family handhelds
=======================================================================================

INSTALL
1. Turn the handheld off and take out the SD card. If it has two slots, use the
   one with your games (on a computer it is usually called EASYROMS).
2. Open the "ports" folder on the card. If there isn't one, look inside "roms",
   or create "ports" next to the other system folders.
3. Copy everything from this zip's "ports" folder into it:
       ports/Brickchord.sh     ports/brickchord/
       ports/Bricklab.sh       ports/bricklab/
       ports/Brickglide.sh     ports/brickglide/
       ports/brick_vendor/     (the libraries all three share: keep it)
   You can leave out an app you don't want; keep brick_vendor either way.
4. Put the card back, turn it on, then Start > Quit > Restart EmulationStation
   (or reboot). The apps appear under Ports.
5. The first launch takes a little longer: it unpacks the libraries for this
   device once, then asks you to press each button and push each stick once.

THE THREE APPS
- Brickchord: the simple one. Seven chord buttons, a beat, effects.
- Bricklab: the groovebox. A looper, patterns, songs, drums, samples, machines.
- Brickglide: chords that glide. Press a chord and the voices slide into it;
  it opens with a guided demo of its controls.

IF IT DOESN'T START
Look at the .log file inside the app's folder (for example
ports/brickglide/brickglide.log). It says which Python the device has and
what went wrong.
 - "python3 not found": the stock firmware has no Python. Install ArkOS
   (or dArkOS) on a fresh card, then try again.
 - Black screen or no sound: send the log to whoever gave you this.
 - Crackles: Settings > Global > Latency > Safe, then relaunch.

These chips are slower than the TrimUI Brick's, so a sound you haven't used
before takes a few seconds to build the first time, and loads instantly after.

Bundled: NumPy (BSD-3-Clause) and pygame (LGPL) wheels for 64-bit ARM,
Python 3.7 to 3.12; the Inter font (SIL OFL). The bundled pygame is only used
if the firmware has none.
